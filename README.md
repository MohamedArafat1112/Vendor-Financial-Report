# Vendor-Financial-Report
An SAP ABAP report designed to display vendor financial transactions, including open and cleared items
## SAP Tables / Views
- LFA1 – Vendor Master Data
- BSIK_VIEW – Open Vendor Items
- BSAK_VIEW – Cleared Vendor Items
- BKPF – Accounting Document Header

## Features
- Object-Oriented ABAP (OOP)
- Open Items and Cleared Items Selection
- Vendor and Company Code Filters
- Posting Date Selection
- SQL INNER JOIN
- ALV Grid Display
- Custom Field Catalog
- Dynamic Row Coloring
- Automatic Column Width Optimization
- ALV Header and Current Date
